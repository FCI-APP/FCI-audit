/** * MOTEUR INTELLIGENT DE RÉDACTION DES CONSTATS DE CONTRÔLE PERMANENT * Analyse sémantique avancée & qualification professionnelle autonome */ function analyserEtRedigerConstat(pcName, ech, ok, ko, tx) { // Étape 1 : Nettoyage et normalisation du texte brut du PC let txt = (pcName || "").trim(); txt = txt.replace(/^[\d\w]+[\/\.\-]\s*/, '').trim(); // Suppression de la numérotation (ex: "1/", "A.") txt = txt.replace(/[\?\.\!]+$/, '').trim(); // Suppression de la ponctuation finale const lower = txt.toLowerCase(); // Détection dynamique de l'unité contrôlée (dossiers, contrats, pièces, opérations, etc.) let unite = "dossiers"; if (lower.includes("contrat") || lower.includes("prestataire")) { unite = "contrats"; } else if (lower.includes("facture") || lower.includes("pièce") || lower.includes("quittance") || lower.includes("justificatif")) { unite = "pièces"; } else if (lower.includes("opération") || lower.includes("transaction") || lower.includes("virement")) { unite = "opérations"; } // Étape 2 & 3 : Analyse sémantique & qualification du manquement métier // CAS 1 : Problématique d'Affichage (ex: Exemple de référence) if (lower.includes("affiché") || lower.includes("affichage")) { let objet = txt.replace(/^(le|la|les|l')\s*/i, '') .replace(/\s+(est-il|est-elle|sont-ils|sont-elles)\s+affiché.*$/i, '') .replace(/^est-ce\s+qu['e]\s*/i, '') .replace(/^affichage\s+du\s+/i, ''); if (ko > 0) { return `L'affichage du ${objet} fait défaut dans ${ko} ${unite} sur les ${ech} ${unite} contrôlés.`; } return `L'affichage du ${objet} est effectif et conforme sur l'ensemble des ${ech} ${unite} contrôlés.`; } // CAS 2 : Problématique de Suivi / Échéancier / Registre if (lower.includes("suivi") || lower.includes("échéancier") || lower.includes("registre") || lower.includes("tenue")) { let objet = txt.replace(/^(est-ce\s+qu['e]|est-ce\s+que|un|une|le|la)\s*/i, '') .replace(/\s+(est-il|est-elle)\s+mis\s+en\s+place.*$/i, '') .replace(/\s+(est|sont)\s+assuré.*$/i, ''); // Capitalise la première lettre si nécessaire objet = objet.charAt(0).toLowerCase() + objet.slice(1); if (ko > 0) { return `Le ${objet} n'est pas assuré pour ${ko} ${unite} sur un échantillon de ${ech} ${unite} vérifiés.`; } return `Le ${objet} est régulièrement tenu et assuré sur l'ensemble des ${ech} ${unite} vérifiés.`; } // CAS 3 : Intégration de Clauses / Autorisations / Droits (ex: Contrats) if (lower.includes("intégration") || lower.includes("clause") || lower.includes("droit d'auteur") || lower.includes("autorisation")) { let contenu = txt.replace(/^(une|l')\s*intégration\s+de\s+la\s+/i, '') .replace(/\s+est-elle\s+prévue.*$/i, '') .replace(/^est-ce\s+qu['e]\s*/i, ''); if (ko > 0) { return `L'absence de clauses contractuelles relatives à ${contenu} a été constatée dans ${ko} ${unite} sur un échantillon de ${ech} ${unite} vérifiés.`; } return `La présence des clauses requises relatives à ${contenu} a été confirmée sur l'ensemble des ${ech} ${unite} vérifiés.`; } // CAS 4 : Présence de pièces / Justificatifs / Signatures / Visas if (lower.includes("présence") || lower.includes("signature") || lower.includes("validation") || lower.includes("visa") || lower.includes("justificatif")) { let element = txt.replace(/^(la\s+présence\s+de|la\s+validation\s+de|le\s+visa\s+de|les)\s+/i, '') .replace(/\s+(est-elle|est-il|sont-ils)\s+.*$/i, '') .replace(/^est-ce\s+qu['e]\s*/i, ''); if (ko > 0) { return `Le défaut de formalisation concernant ${element} a été relevé sur ${ko} ${unite} sur les ${ech} ${unite} contrôlés.`; } return `La présence et la conformité de ${element} sont avérées sur la totalité des ${ech} ${unite} contrôlés.`; } // CAS 5 : Respect des Délais / Délais de traitement if (lower.includes("délai") || lower.includes("retard")) { if (ko > 0) { return `Le non-respect des délais prescrits est constaté pour ${ko} ${unite} sur un échantillon de ${ech} ${unite} vérifiés.`; } return `Le respect des délais réglementaires et opérationnels est garanti sur l'ensemble des ${ech} ${unite} vérifiés.`; } // CAS GÉNÉRIQUE D'AUDIT : Reconstitution fluide sans tournure artificielle let sujetPropre = txt.replace(/^(est-ce\s+qu['e]|est-ce\s+que|est-il|est-elle|y\s+a-t-il|une|un|le|la|les)\s+/i, '') .replace(/\s+(est-elle|est-il|sont-ils|sont-elles)\s+.*$/i, ''); sujetPropre = sujetPropre.charAt(0).toLowerCase() + sujetPropre.slice(1); if (ko > 0) { return `La non-conformité relative à ${sujetPropre} a été relevée dans ${ko} ${unite} sur les ${ech} ${unite} vérifiés.`; } return `La parfaite conformité concernant ${sujetPropre} a été constatée sur la totalité des ${ech} ${unite} vérifiés.`; } /** * Fonction principale appelée par l'interface FCI FicheControle.html */ function genererTexteConstat(ev, pcName) { const ech = ev.echantillon || 0; const ok = ev.nombreOk || 0; const ko = ev.nombreKo || 0; const tx = ev.tauxConformite || "0.00"; if (ech === 0) { return `Le contrôle n'a pas pu être réalisé (échantillon égal à 0 dossier), soit un taux de conformité de 0,00 %.`; } // Génération du constat analytique professionnel return analyserEtRedigerConstat(pcName, ech, ok, ko, tx); }
